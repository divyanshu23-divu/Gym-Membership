Core Features & Architecture

⏳

Dynamic Countdown Engine

Days remaining dynamically computed from current date. Color-coded thresholds: Green (>15d), Orange (7–15d), Red (<7d with warning banner), and Grey (Expired).

🔄

Smart Renewal Extension

Members submit renewal requests with custom plans. Staff approvals automatically extend from active end dates or today's date if expired.

📅

Attendance & Streaks

Strict SQLite UNIQUE(member_id, date) constraint prevents duplicate check-ins. Interactive calendar highlights attended days with unbroken streaks.

📈

Progress Analytics (Chart.js)

Interactive line charts tracking weight and measurements over time, coupled with automated Mifflin-St Jeor daily calorie targets.

🏋️

Trainer Workouts

Coaches assign tailored templates (Beginner, Hypertrophy, HIIT). Members check off exercises, sets, and reps day-by-day.

🛡️

Role-Based Security

JWT bearer tokens, bcrypt password hashing, parameterized SQL queries, and complete role-restricted endpoints for Admin and Members.
